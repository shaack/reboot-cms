# Page with frontmatter

The page starts with YAML frontmatter, which is not displayed in the page. It looks like this:

```
---
title: Page with frontmatter
author: Stefan Haack
hide-nav: true
---
```

The template reads `title` and `author` for the HTML head, and `hide-nav: true` removes the navigation on this page.
