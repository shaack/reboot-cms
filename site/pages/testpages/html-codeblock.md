# HTML in a code block

A fenced code block may contain HTML comments. They must not be mistaken for block comments, so this page has to render as a single text block with the code below shown as code.

```html
<body>
Lorem ipsum dolor sit amet, consectetur adipisicing elit, sed do eiusmod tempor incididunt ut labore et dolore magna aliqua.

<!-- This is a html comment, not a block -->

</body>
```
